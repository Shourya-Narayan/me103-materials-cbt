# ME 103 Studio — Engineering Materials CBT

Interactive Computer-Based Test (CBT) practice portal covering all 17 chapters + Chapter 19 exam traps of **ME 103 Engineering Materials (Chemistry)** with **576 verified MCQs**.

## Features
- **576 Syllabus-Verified MCQs** across 15 modules (215 Conceptual · 154 Numerical · 84 Exam Traps · 71 Diagram · 52 Formula)
- **Two Modes:** Interactive Practice Mode (instant feedback & worked explanations) and Timed Mock Exam Mode (NTA/GATE-style palette & optional negative marking)
- **17 Custom SVG Reference Diagrams** with Expand Lightbox (`Fe–Fe₃C`, `Pb–Sn`, `Cu–Ni`, `TTT`, `Al–Cu`, `Cu–Zn`, `Stress–Strain`, `ROM`, `Energy Bands`, `CZ/FZ`, `PBR`, etc.)
- **Built-in Exam Tools:** Searchable Master Formula Sheet (`F`), Scientific Calculator with ME 103 constants & history (`K`), option strike-out elimination, keyboard shortcuts, and automatic Mistake Queue & Bookmarks (`localStorage`)

## Run Locally
Open `index.html` directly in any browser, or run:
```bash
python3 -m http.server 8765
```
Then visit `http://localhost:8765/`.
